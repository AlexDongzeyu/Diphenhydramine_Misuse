# figures

Purpose: final figures generated from 05_final/cohort_analysis.csv.

Files
- cohort_flow.png: cohort count flow summary from teen DEMO to final analysis table.
- acb_by_age_group.png: total ACB burden across age groups.
- logistic_odds_ratios.png: odds-ratio forest plot for the multivariable cardiac toxicity model.
- cardiac_risk_roc.png: ROC curve for the cardiac risk model.
- overview_dashboard.png: four-panel summary figure for presentation use.
- acb_vs_severity.png: supplementary lowess plot of ACB burden versus severity.
- age_histogram.png, acb_with_dph_histogram.png, acb_codrugs_only_histogram.png, codrug_count_histogram.png, severity_histogram.png: distribution diagnostics.
- age_qq_plot.png, acb_with_dph_qq_plot.png, acb_codrugs_only_qq_plot.png, codrug_count_qq_plot.png, severity_qq_plot.png: Q-Q diagnostics for normality checks.

How it connects
- All figures are generated by 06_analysis/build_analysis_outputs.py.
- overview_dashboard.png composes the main flow, age-group, odds-ratio, and ROC figures.
