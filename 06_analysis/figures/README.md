# figures

Purpose: final figures generated from 05_final/cohort_analysis.csv.

Manuscript figures
- cohort_flow.png: cohort count flow from all adolescent DEMO records (217,507) down to the confirmed DPH analysis cohort (211).
- acb_by_age_group.png: total ACB burden across age groups with Dunn post-hoc comparisons (Kruskal-Wallis p=0.018).
- logistic_odds_ratios.png: odds-ratio forest plot for the multivariable cardiac toxicity logistic model.
- cardiac_risk_roc.png: ROC curve for the cardiac risk model (AUC=0.753).
- overview_dashboard.png: four-panel summary figure (flow, age-group ACB, forest plot, ROC) for presentation use.
- acb_vs_severity.png: LOWESS regression of ACB burden versus case severity (Spearman ρ=0.137, p=0.046).

Distribution diagnostic figures
- age_histogram.png, age_qq_plot.png: age distribution and normality check.
- acb_with_dph_histogram.png, acb_with_dph_qq_plot.png: total ACB (with DPH) distribution and normality check.
- acb_codrugs_only_histogram.png, acb_codrugs_only_qq_plot.png: co-drug ACB distribution and normality check.
- codrug_count_histogram.png, codrug_count_qq_plot.png: co-drug count distribution and normality check.
- severity_histogram.png, severity_qq_plot.png: max severity distribution and normality check.

How it connects
- All 16 figures are generated by 06_analysis/build_analysis_outputs.py.
- overview_dashboard.png composes cohort_flow, acb_by_age_group, logistic_odds_ratios, and cardiac_risk_roc.
