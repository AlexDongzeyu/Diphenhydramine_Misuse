# tables

Purpose: final statistical result tables generated from 05_final/cohort_analysis.csv.

Files
- descriptive_summary.csv: descriptive statistics for continuous and categorical study variables.
- normality_checks.csv: Shapiro-Wilk normality results for the main continuous variables.
- nonparametric_results.csv: Mann-Whitney, Kruskal-Wallis, and Spearman test results.
- age_group_posthoc.csv: Dunn post-hoc comparisons for the age-group ACB analysis.
- logistic_model_full.csv: odds ratios, confidence intervals, and p-values for the multivariable logistic model.
- logistic_model_fit.csv: model fit metrics including AIC, pseudo-R2, and AUC.
- logistic_model_predictions.csv: per-case predicted probabilities from the logistic model.

How it connects
- All tables are generated by 06_analysis/build_analysis_outputs.py.
- results_summary.md and overview_dashboard.png summarize the results stored here.
