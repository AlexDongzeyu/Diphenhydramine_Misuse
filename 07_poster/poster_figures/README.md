# 07_poster/poster_figures

## What this folder is

Poster figure outputs generated from analysis results.

## Subfolders

- `final/`: final figures for poster placement.
- `diagnostics/`: supplementary figures.
- `docs/`: figure manifest and layout file.

## How files are created

- Generated by `06_analysis/build_poster_figures.py`.
- Source figures are read from `06_analysis/figures/`.

## Rebuild command

```powershell
python 06_analysis/build_poster_figures.py
```
